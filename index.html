Browser
Customization

CSS-модификации Firefox с автоустановщиком профиля и единый пользовательский скрипт Browser Tweaks v1.3.0: глобальный шрифт Ubuntu Light, универсальные инструменты видео и URL, а также модули для YouTube.

С чего начать

1. Настроить Firefox

Запусти автоустановщик install.ps1 / install.sh (с резервной копией и user.js) или скопируй тему вручную.

Руководство Firefox

2. Установить Browser Tweaks

Поставь расширение Violentmonkey и подключи единый скрипт Browser Tweaks v1.3.0 с автообновлением из репозитория.

Установить скрипт Violentmonkey

Возможности

Firefox Customization

Коллекция стилей на базе Firefox-Mod-Blur: userChrome.css, userContent.css, готовый шаблон user.js и 10 модульных CSS-модов, каждый из которых теперь переключается на лету через флаги about:config без редактирования файлов.

Документация и флаги Исходный проект

Browser Tweaks v1.3.0

Шрифт Ubuntu Light: глобальное вкл/выкл, индивидуальная интенсивность для отдельных сайтов, защита формул KaTeX/MathJax и терминалов xterm, менеджер исключений.

Для всех сайтов: скорость любого HTML5-видео (Shift + колесо, Ctrl + ↑/↓/0), Картинка в картинке (Alt + P), очистка трекеров URL и выбор клавиши открытия панели.

Для YouTube: скрытие мусора по 5 категориям, авто-широкий плеер, режим фокуса без рекомендаций, память скорости по каналам, снимок кадра в 4K (Alt + Shift + S), перевод комментариев и авто-качество.
