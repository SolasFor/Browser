# Browser Customization

Коллекция CSS-модификаций Firefox и единый пользовательский скрипт Browser Tweaks для браузера. Репозиторий объединяет настройки интерфейса Firefox и инструменты для повседневного просмотра сайтов.

## Содержание

- [Firefox Customization](firefox-customization/README.md) — установка CSS-модов, параметры `about:config` и визуальные примеры.
- [Browser Tweaks](userscripts/browser-tweaks-unified.user.js) — единый userscript: глобальный шрифт Ubuntu Light и дополнительные настройки YouTube.

## Firefox Customization

## Browser Tweaks

В репозитории используется один пользовательский скрипт — **Browser Tweaks**. Для установки потребуется расширение [Violentmonkey](https://violentmonkey.github.io/).

**[Установить Browser Tweaks](userscripts/browser-tweaks-unified.user.js)**

### Ubuntu Light — все сайты

- Применяет шрифт Ubuntu Light к основному тексту страниц.
- Предусмотрены два уровня интенсивности: «Мягкая» и «Выраженная».
- Можно исключить текущий сайт из применения шрифта или снова включить его.
- Список исключений и выбранная интенсивность сохраняются между посещениями.

### YouTube Tweaks — только YouTube

- Плавные CSS-анимации основных областей интерфейса.
- Скрытие выбранных элементов страницы и видеоплеера.
- Компактный режим с уменьшенными отступами.
- Изменение скорости воспроизведения колесом мыши при зажатом `Shift`.
- Перевод комментариев на русский язык через Google Translate; результаты сохраняются в локальном кэше.
- Автоматический выбор качества видео: 720p, 1080p, 1440p или 2160p с подбором доступного уровня.
- Горячие клавиши скорости: `Ctrl + ↑`, `Ctrl + ↓`, `Ctrl + 0`.
- Настраиваемый шаг изменения скорости: 0,05×, 0,1×, 0,25× или 0,5×.

### Управление

| Клавиша | Действие |
| --- | --- |
| `F2` | Открыть или закрыть панель настроек |
| `Alt + Shift + U` | Исключить текущий сайт из Ubuntu Light или снова включить шрифт |
| `Esc` | Закрыть панель настроек |
| `Shift + колесо мыши` | Изменить скорость видео на YouTube, если функция включена |
| `Ctrl + ↑ / ↓` | Увеличить или уменьшить скорость видео, если горячие клавиши включены |
| `Ctrl + 0` | Вернуть скорость видео к 1× |

На обычных сайтах панель содержит настройки Ubuntu Light. На YouTube в общей панели доступны и настройки шрифта, и функции YouTube Tweaks. Настройки YouTube включаются отдельно флажками и сохраняются в локальном хранилище сайта.

### Установка

1. Установите расширение [Violentmonkey](https://violentmonkey.github.io/).
2. Откройте файл [Browser Tweaks](userscripts/browser-tweaks-unified.user.js).
3. Подтвердите установку в интерфейсе Violentmonkey.
4. Откройте панель настроек клавишей `F2`.

В репозитории оставлен только объединённый userscript. Старые отдельные файлы Ubuntu Light Font и YouTube Tweaks удалены, поэтому устанавливать или обновлять их отдельно не требуется.

## Предупреждение

CSS-моды Firefox зависят от внутренней разметки браузера и могут перестать работать после обновления Firefox. Селекторы YouTube Tweaks также зависят от разметки YouTube и могут потребовать обновления. Функция перевода отправляет текст комментария сервису Google Translate.
