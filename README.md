# Browser Customization

Набор инструментов для персонализации браузера Firefox: CSS-модификации интерфейса и единый пользовательский скрипт **Browser Tweaks**. Проект помогает настроить внешний вид браузера и добавить полезные функции для повседневного просмотра сайтов.

## Содержание

- [Firefox Customization](#firefox-customization) — оформление интерфейса Firefox с помощью CSS, настройка `about:config` и дополнительные модификации.
- [Browser Tweaks](#browser-tweaks) — единый userscript для глобального шрифта Ubuntu Light и дополнительных функций YouTube.
- [Установка](#установка-browser-tweaks) — подключение скрипта через Violentmonkey.

---

## Firefox Customization

Раздел содержит набор пользовательских CSS-стилей и дополнительных настроек Firefox. С их помощью можно изменить оформление вкладок, панели инструментов, меню расширений, поисковой строки и других элементов интерфейса.

В руководстве доступны:

- инструкция по включению поддержки пользовательских CSS-стилей;
- описание параметров `about:config`;
- дополнительные CSS-модификации;
- скриншоты и примеры оформления;
- рекомендации по подключению и настройке файлов.

**[Перейти к руководству Firefox Customization →](firefox-customization/README.md)**

Перед установкой рекомендуется сохранить резервную копию папки `chrome` профиля Firefox. CSS-оформление может требовать корректировки после крупных обновлений браузера.

## Browser Tweaks

**Browser Tweaks** — единый пользовательский скрипт, объединяющий настройки шрифта Ubuntu Light для сайтов и дополнительные инструменты для YouTube. Функции разделены по назначению: глобальные настройки применяются на обычных сайтах, а инструменты YouTube активируются только на YouTube.

<p align="center">
  <a href="userscripts/browser-tweaks-unified.user.js"><strong>Установить Browser Tweaks</strong></a>
</p>

Для установки и управления скриптом используется расширение [Violentmonkey](https://violentmonkey.github.io/).

### Ubuntu Light — глобальные настройки

- Применение шрифта Ubuntu Light к текстовому содержимому сайтов.
- Два уровня интенсивности отображения: «Мягкая» и «Выраженная».
- Исключение отдельных сайтов из применения шрифта.
- Возможность быстро вернуть шрифт на исключённый сайт.
- Сохранение выбранной интенсивности и списка исключений.

### YouTube Tweaks — инструменты YouTube

- Плавные анимации основных элементов интерфейса.
- Скрытие выбранных элементов страницы и видеоплеера.
- Компактный режим с уменьшенными отступами.
- Изменение скорости воспроизведения прокруткой колеса мыши при зажатом `Shift`.
- Перевод комментариев на русский язык через Google Translate с локальным кэшированием результатов.
- Автоматический выбор качества видео: 720p, 1080p, 1440p или 2160p с выбором доступного варианта.
- Управление скоростью с помощью клавиатуры.
- Настраиваемый шаг изменения скорости: 0,05×, 0,1×, 0,25× или 0,5×.

Функции YouTube можно включать и отключать отдельно в панели настроек.

### Горячие клавиши

| Сочетание | Действие |
| --- | --- |
| `F2` | Открыть или закрыть панель настроек |
| `Alt + Shift + U` | Добавить текущий сайт в исключения Ubuntu Light или убрать его из исключений |
| `Esc` | Закрыть панель настроек |
| `Shift + колесо мыши` | Изменить скорость воспроизведения на YouTube, если функция включена |
| `Ctrl + ↑` | Увеличить скорость воспроизведения |
| `Ctrl + ↓` | Уменьшить скорость воспроизведения |
| `Ctrl + 0` | Вернуть скорость воспроизведения к 1× |

На обычных сайтах панель `F2` содержит настройки Ubuntu Light. На YouTube в ней также доступны параметры YouTube Tweaks.

## Установка Browser Tweaks

1. Установите расширение [Violentmonkey](https://violentmonkey.github.io/) для своего браузера.
2. Откройте файл [browser-tweaks-unified.user.js](userscripts/browser-tweaks-unified.user.js).
3. Подтвердите установку скрипта в открывшемся интерфейсе Violentmonkey.
4. Перейдите на любой сайт и нажмите `F2`, чтобы открыть панель настроек.
5. Настройте Ubuntu Light и, при необходимости, функции YouTube.

В репозитории поддерживается одна актуальная объединённая версия userscript. Старые отдельные скрипты Ubuntu Light Font и YouTube Tweaks удалены. Для обновлений используется адрес скрипта, указанный в его метаданных; при включённой проверке обновлений Violentmonkey сможет получать новые версии из репозитория.

## Совместимость и замечания

- **Firefox CSS:** пользовательские стили зависят от внутренней структуры интерфейса Firefox. После обновления браузера некоторые селекторы могут потребовать изменений.
- **YouTube:** разметка и элементы управления YouTube периодически меняются, поэтому отдельные функции скрипта могут нуждаться в адаптации.
- **Перевод комментариев:** для перевода используется Google Translate; текст комментариев передаётся внешнему сервису.
- **Резервные копии:** перед заменой CSS-файлов Firefox рекомендуется сохранить текущую конфигурацию профиля.

Если обнаружена ошибка или есть предложение по улучшению, сообщите о проблеме в разделе [Issues](https://github.com/SolasFor/Browser/issues).
