# Browser Customization

Набор инструментов для персонализации браузера Firefox: CSS-модификации интерфейса и единый пользовательский скрипт **Browser Tweaks**. Проект помогает настроить внешний вид браузера и добавить полезные функции для повседневного просмотра сайтов.

## Содержание

- [Firefox Customization](#firefox-customization) — оформление интерфейса Firefox с помощью CSS, настройка `about:config` и дополнительные модификации.
- [Browser Tweaks](#browser-tweaks) — единый userscript для глобального шрифта Ubuntu Light и дополнительных функций YouTube.
- [Установка](#установка-browser-tweaks) — подключение скрипта через Violentmonkey.

---

## Firefox Customization

Раздел содержит набор пользовательских CSS-стилей и дополнительных настроек Firefox. С их помощью можно изменить оформление вкладок, панели инструментов, меню расширений, поисковой строки и других элементов интерфейса.

В руководстве доступны:

- автоматическая установка в профиль через `install.ps1` (Windows) и `install.sh` (Linux/macOS) с резервным копированием и готовым `user.js`;
- инструкция по ручному подключению CSS-стилей;
- описание параметров `about:config` и индивидуальных флагов отключения всех 10 модульных CSS-модов;
- скриншоты и примеры оформления.

**[Перейти к руководству Firefox Customization →](firefox-customization/README.md)**

Перед установкой рекомендуется сохранить резервную копию папки `chrome` профиля Firefox. CSS-оформление может требовать корректировки после крупных обновлений браузера.

## Browser Tweaks

**Browser Tweaks** — единый пользовательский скрипт, объединяющий настройки шрифта Ubuntu Light для сайтов и дополнительные инструменты для YouTube. Функции разделены по назначению: глобальные настройки применяются на обычных сайтах, а инструменты YouTube активируются только на YouTube.

<p align="center">
  <a href="https://raw.githubusercontent.com/SolasFor/Browser/main/userscripts/browser-tweaks-unified.user.js"><strong>Установить Browser Tweaks</strong></a>
</p>

Для установки и управления скриптом используется расширение [Violentmonkey](https://violentmonkey.github.io/).

### Ubuntu Light — глобальные настройки

- Применение шрифта Ubuntu Light к текстовому содержимому сайтов с защитой кода, иконочных глифов, математических формул (**KaTeX**, **MathJax**, `<math>`) и веб-терминалов (**xterm.js**).
- Полное глобальное выключение кастомных шрифтов одним переключателем (на всех сайтах и в собственном интерфейсе скрипта, с удалением `@font-face`), чтобы при желании использовать только браузерные и YouTube-инструменты.
- Локальное кэширование файла шрифта в расширении (`@resource`) с резервной загрузкой из репозитория.
- Два уровня интенсивности отображения («Мягкая» и «Выраженная») плюс выбор индивидуального режима для конкретного сайта прямо в панели (`Как глобально` / `Мягкая только здесь` / `Выраженная только здесь` / `Исключён`).
- Исключение отдельных сайтов с наглядным экранным уведомлением (OSD) и полным управлением списком исключений прямо в панели (добавление по домену или URL, отметка текущего сайта, удаление отдельных записей и очистка списка).
- Мгновенная синхронизация настроек между открытыми вкладками.

### Универсальные функции браузера — для всех сайтов

- Управление скоростью любого HTML5-видео прокруткой `Shift + колесо мыши` над плеером и горячими клавишами `Ctrl + ↑ / ↓ / 0` (Twitch, VK Видео, Coursera, Telegram Web и др.).
- Быстрое переключение режима «Картинка в картинке» (Picture-in-Picture) клавишами `Alt + P` со снятием искусственной блокировки `disablePictureInPicture`.
- Тихая очистка трекинговых параметров URL (`utm_*`, `fbclid`, `yclid`, `gclid`, `igshid`, `si` на YouTube и др.) в адресной строке через `history.replaceState` без перезагрузки страницы и при копировании ссылок.
- Настраиваемая горячая клавиша открытия панели (`F2`, `Alt + Shift + B`, `Alt + Shift + M` или `Ctrl + Shift + F2`), чтобы не конфликтовать с переименованием и редактированием ячеек в веб-приложениях.

### YouTube Tweaks — инструменты YouTube

- Плавные анимации основных элементов интерфейса без рывков макета.
- Гибкое скрытие лишних элементов с настройкой по 5 категориям (оверлеи плеера, кнопки под видео, разделы бокового меню, элементы шапки поиска, промо Premium и полки Shorts).
- Автоматическое раскрытие широкого плеера (Theater Mode) при открытии ролика.
- Режим фокуса со скрытием правой колонки рекомендаций (`#related`) и конечных заставок.
- Компактный режим с уменьшенными отступами.
- Скриншот чистого кадра видео в нативном разрешении потока (вплоть до 4K) без оверлеев плеера — кнопкой камеры в плеере или сочетанием `Alt + Shift + S` (сохранение PNG и копирование в буфер обмена).
- Управление скоростью колесом мыши (`Shift`) и с клавиатуры с настраиваемым шагом (`0,05×`, `0,1×`, `0,25×`, `0,5×`) и автоматическим запоминанием привычной скорости отдельно для каждого канала YouTube.
- Перевод комментариев на русский язык через Google Translate с локальным кэшированием результатов и поддержкой динамической подгрузки YouTube.
- Автоматический выбор качества видео: 720p, 1080p, 1440p или 2160p с подбором ближайшего доступного варианта.

Все настройки хранятся централизованно в хранилище Violentmonkey (с автоматическим переносом прежних настроек из `localStorage`), поддерживают резервное копирование и перенос в формате JSON (`Экспорт JSON` / `Импорт JSON`, а также генерацию пресета на [главной странице проекта](https://solasfor.github.io/Browser/#configurator)), а сама перетаскиваемая панель изолирована от стилей сайтов через Shadow DOM и доступна из меню иконки Violentmonkey.

### Горячие клавиши

| Сочетание | Действие |
| --- | --- |
| `F2` *(настраивается)* | Открыть или закрыть панель настроек (`F2`, `Alt + Shift + B`, `Alt + Shift + M` или `Ctrl + Shift + F2`) |
| `Alt + Shift + F` | Полностью включить или выключить кастомный шрифт на всех сайтах и в панели |
| `Alt + Shift + U` | Добавить текущий сайт в исключения Ubuntu Light или убрать его из исключений |
| `Esc` | Закрыть панель настроек |
| `Alt + P` | Включить или выключить «Картинку в картинке» (PiP), если функция включена |
| `Alt + Shift + S` | Сохранить и скопировать чистый кадр видео на YouTube, если функция включена |
| `Shift + колесо мыши` | Изменить скорость воспроизведения над видеоплеером |
| `Ctrl + ↑` | Увеличить скорость воспроизведения |
| `Ctrl + ↓` | Уменьшить скорость воспроизведения |
| `Ctrl + 0` | Вернуть скорость воспроизведения к 1× |

На обычных сайтах панель содержит настройки Ubuntu Light, универсальные функции браузера и резервное копирование JSON. На YouTube в ней также доступны параметры YouTube Tweaks.

## Установка Browser Tweaks

1. Установите расширение [Violentmonkey](https://violentmonkey.github.io/) для своего браузера.
2. Откройте прямую ссылку на скрипт [browser-tweaks-unified.user.js](https://raw.githubusercontent.com/SolasFor/Browser/main/userscripts/browser-tweaks-unified.user.js) (исходный код: [`userscripts/browser-tweaks-unified.user.js`](userscripts/browser-tweaks-unified.user.js)).
3. Подтвердите установку скрипта в открывшемся интерфейсе Violentmonkey.
4. Перейдите на любой сайт и нажмите `F2`, чтобы открыть панель настроек.
5. Настройте Ubuntu Light и, при необходимости, функции YouTube.

В репозитории поддерживается одна актуальная объединённая версия userscript. Старые отдельные скрипты Ubuntu Light Font и YouTube Tweaks удалены. Для обновлений используется адрес скрипта, указанный в его метаданных; при включённой проверке обновлений Violentmonkey сможет получать новые версии из репозитория.

## Структура проекта

```text
Browser/
├── firefox-customization/
│   ├── README.md
│   ├── install.ps1
│   ├── install.sh
│   ├── user.js
│   └── chrome/
├── fonts/
│   └── Ubuntu Light.woff2
├── userscripts/
│   └── browser-tweaks-unified.user.js
├── index.html
└── README.md
```

- `firefox-customization/` — руководство, автоустановщики (`install.ps1`, `install.sh`), шаблон `user.js` и CSS-файлы оформления Firefox.
- `fonts/` — веб-шрифт `Ubuntu Light.woff2`, загружаемый пользовательским скриптом.
- `userscripts/` — единый пользовательский скрипт Browser Tweaks.
- `index.html` — главная страница проекта с интерактивным генератором пресетов `user.js` и `browser-tweaks-settings.json`.

## Совместимость и замечания

- **Firefox CSS:** пользовательские стили зависят от внутренней структуры интерфейса Firefox. После обновления браузера некоторые селекторы могут потребовать изменений.
- **YouTube:** разметка и элементы управления YouTube периодически меняются, поэтому отдельные функции скрипта могут нуждаться в адаптации.
- **Перевод комментариев:** для перевода используется Google Translate; текст комментариев передаётся внешнему сервису.
- **Резервные копии:** перед заменой CSS-файлов Firefox рекомендуется сохранить текущую конфигурацию профиля.

Если обнаружена ошибка или есть предложение по улучшению, сообщите о проблеме в разделе [Issues](https://github.com/SolasFor/Browser/issues).
