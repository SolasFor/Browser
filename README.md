# Browser Customization

Набор пользовательских скриптов Violentmonkey и CSS-модов для Firefox. Проект объединяет настройки браузера на основе темы [Firefox-Mod-Blur](https://github.com/datguypiko/Firefox-Mod-Blur).

## Userscripts

Скрипты предназначены для [Violentmonkey](https://violentmonkey.github.io/):

- [YouTube Tweaks](https://raw.githubusercontent.com/SolasFor/Browser/main/userscripts/youtube-tweaks.user.js) — небольшие улучшения интерфейса YouTube.
- [Ubuntu Light Font](https://raw.githubusercontent.com/SolasFor/Browser/main/userscripts/ubuntu-light-font.user.js) — подключение шрифта Ubuntu Light на поддерживаемых страницах.

Для установки откройте ссылку `raw.githubusercontent.com` в браузере с установленным Violentmonkey и подтвердите установку.

## Firefox Customization

Папка [`firefox-customization`](firefox-customization/) содержит `userChrome.css`, `userContent.css` и дополнительные CSS-моды на основе [Firefox-Mod-Blur](https://github.com/datguypiko/Firefox-Mod-Blur).

Инструкции по установке: [`firefox-customization/README.md`](firefox-customization/README.md).
