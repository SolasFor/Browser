# Browser Customization

Коллекция CSS-модификаций Firefox и пользовательских скриптов для браузера. В репозитории собраны настройки интерфейса Firefox, ресурсы темы и userscripts для [Violentmonkey](https://violentmonkey.github.io/).

## Содержание

- [Firefox Customization](firefox-customization/README.md) — установка CSS-модов, параметры `about:config` и визуальные примеры.
- **Browser Tweaks (объединённый скрипт)** — общий Ubuntu Light для сайтов и инструменты YouTube в одной панели. Код объединённой версии предоставлен отдельно; пока не устанавливайте одновременно её и старые самостоятельные скрипты.
- [YouTube Tweaks — самостоятельная версия](userscripts/youtube-tweaks.user.js) — прежний userscript только для YouTube.
- [Ubuntu Light Font — самостоятельная версия](userscripts/ubuntu-light-font.user.js) — прежний userscript глобального шрифта.

## Userscripts

Для установки и управления пользовательскими скриптами используйте Violentmonkey.

### Browser Tweaks — объединённая версия

Объединённый вариант сочетает глобальное управление шрифтом Ubuntu Light и функции YouTube Tweaks.

**Ubuntu Light — на всех сайтах:**
- применение шрифта Ubuntu Light к текстовым элементам;
- два уровня интенсивности: «Мягкая» и «Выраженная»;
- исключение текущего сайта из применения шрифта и обратное включение;
- горячая клавиша `Alt + Shift + U`.

**YouTube Tweaks — только на YouTube:**
- плавные анимации интерфейса;
- скрытие выбранных элементов страницы и плеера;
- компактный режим;
- изменение скорости воспроизведения колесом мыши с зажатым `Shift`;
- перевод комментариев на русский язык через Google Translate с локальным кэшем;
- выбор качества видео (720p, 1080p, 1440p и 2160p) с подбором доступного варианта;
- горячие клавиши скорости воспроизведения: `Ctrl + ↑`, `Ctrl + ↓`, `Ctrl + 0`;
- выбор шага изменения скорости: 0,05×, 0,1×, 0,25× или 0,5×.

На YouTube настройки шрифта находятся в общей панели вместе с функциями YouTube Tweaks. На остальных сайтах доступна панель глобального шрифта.

**Горячие клавиши:**
- `F2` — открыть или закрыть панель настроек;
- `Alt + Shift + U` — добавить текущий сайт в исключения Ubuntu Light или убрать его из исключений;
- `Esc` — закрыть панель.

### Самостоятельные версии (legacy)

В репозитории пока также хранятся прежние отдельные скрипты:
- [YouTube Tweaks](userscripts/youtube-tweaks.user.js)
- [Ubuntu Light Font](userscripts/ubuntu-light-font.user.js)

Это самостоятельные версии, а не части объединённого скрипта. Не запускайте их одновременно с объединённой версией: дублирующиеся стили и обработчики клавиш могут конфликтовать.

## Предупреждение

CSS-моды Firefox зависят от внутренней разметки браузера и могут перестать работать после обновления Firefox. Селекторы YouTube Tweaks также зависят от текущей разметки YouTube и могут требовать обновления. Перевод комментариев отправляет их текст сервису Google Translate. Перед изменениями Firefox сохраните резервную копию папки профиля `chrome`.
