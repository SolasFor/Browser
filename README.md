# Browser Customization

Коллекция небольших улучшений для браузера Firefox и пользовательских скриптов для сайтов. Репозиторий содержит CSS-настройки Firefox, ресурсы темы и скрипты для [Violentmonkey](https://violentmonkey.github.io/).

## Содержание

- [Firefox Customization](firefox-customization/README.md) — установка CSS-модов и визуальные примеры.
- [YouTube Tweaks](userscripts/youtube-tweaks.user.js) — улучшения интерфейса YouTube.
- [Ubuntu Light Font](userscripts/ubuntu-light-font.user.js) — пользовательский шрифт для поддерживаемых страниц.

## Firefox Customization

Набор основан на [Firefox-Mod-Blur](https://github.com/datguypiko/Firefox-Mod-Blur). В документации есть описание модификаций, параметры `about:config`, скриншоты и инструкции по установке.

**[Открыть руководство и галерею скриншотов →](firefox-customization/README.md)**

## Источник и благодарности

Визуальные модификации Firefox основаны на проекте [datguypiko/Firefox-Mod-Blur](https://github.com/datguypiko/Firefox-Mod-Blur). Скриншоты в руководстве взяты из его README и используются как наглядные примеры оригинальных модификаций. Полный список файлов, лицензии и актуальные сведения смотрите в исходном проекте.

## Предупреждение

Firefox CSS-моды зависят от внутренней разметки браузера и могут перестать работать после обновления Firefox. Перед изменениями сохраните резервную копию папки профиля `chrome` и включайте дополнительные моды по одному.
